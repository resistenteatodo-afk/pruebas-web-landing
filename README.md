# 🚀 Landing Page Moderna - Modo Oscuro

Una landing page moderna, responsiva y estilizada en modo oscuro creada con **React**, **Tailwind CSS** y **Framer Motion**.

---

## 🛠️ Tecnologías Utilizadas

* **Framework/Librería:** React + Vite
* **Estilos:** Tailwind CSS
* **Animaciones:** Framer Motion
* **Iconos:** Lucide React

---

## ⚡ Características

* 🌙 **Diseño Dark Mode:** Interfaz adaptada en tonos oscuros con gradientes modernos.
* 📱 **Totalmente Responsiva:** Se adapta perfectamente a dispositivos móviles, tablets y computadoras.
* 🎯 **Navegación Fluida:** Scroll suave entre secciones (`#inicio`, `#caracteristicas`, `#precios`, `#contacto`).
* 🇪🇸 **Español:** Textos y componentes adaptados totalmente al idioma español.
